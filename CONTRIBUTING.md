# Contributing

Thanks for helping make this list better! Here's how to add a resource.

## How to submit

**Open a pull request, not an issue.** Issues asking to add a resource will be closed.

1. Fork the repo and edit `README.md`.
2. Add **one row** to the table in the section that fits best.
3. Follow the existing format:

   ```
   | [Resource Name](https://example.com/) | One sentence describing what it is and why it's useful. |
   ```

4. Keep the description short, plain, and factual. No marketing copy.
5. If you built the resource, say so in the PR description.

## What gets accepted

A resource is a good fit if it:

- Is useful to designers or design-minded developers
- Is free to use, or has a real free tier (not just a trial or a sample that points to a paid product)
- Works today and has real content behind it
- Is in English or usable without reading another language
- Adds something the list doesn't already cover

## What gets declined

- Small sample packs that mainly promote a paid product
- Developer APIs or niche tools that aren't design resources
- Entries that duplicate something already on the list
- Descriptions that read like ads
- Sites that are parked, broken, or paywalled

Submissions are reviewed as time allows. If yours is declined, you're welcome to open a new PR later if the resource has grown or changed.
